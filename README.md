# linuxtools
自用 Linux 小工具脚本

### 默认一键命令
~~~
bash <(curl -s https://raw.githubusercontent.com/xkatld/LinuxTools/refs/heads/main/linuxtools.sh)
~~~
~~~
wget -qO- https://raw.githubusercontent.com/xkatld/LinuxTools/refs/heads/main/linuxtools.sh | bash
~~~

### 中国大陆地区加速命令
~~~
bash <(curl -s https://ghfast.top/https://raw.githubusercontent.com/xkatld/LinuxTools/refs/heads/main/linuxtools.sh)
~~~
~~~
wget -qO- https://ghfast.top/https://raw.githubusercontent.com/xkatld/LinuxTools/refs/heads/main/linuxtools.sh | bash
~~~
